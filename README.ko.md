# Awesome Algorithms Education [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> 알고리즘을 배우고 연습하기 위한 강좌, 온라인 저지, 시각화 도구, 도서, 대회를 엄선한 목록입니다.

유료라고 표시한 항목 외에는 모두 무료로 읽거나 사용할 수 있으며, 한국어 자료에는 따로 표시를 두어 영어와 한국어 학습자 모두가 자신에게 맞는 자료를 찾을 수 있게 했습니다. 알고리즘 구현 코드나 대회 특화 자료는 [Awesome Competitive Programming](https://github.com/lnishan/awesome-competitive-programming#readme)과 [Awesome Algorithms](https://github.com/tayllan/awesome-algorithms#readme)을 참고하세요.

만약 기여하고 싶다면, [기여 가이드](CONTRIBUTING.md) 문서를 확인하세요.

## Courses
> 강좌

#### Introductory
> 초급 강좌

- [Algorithms](https://www.khanacademy.org/computing/computer-science/algorithms) - Khan Academy / Thomas Cormen이 공동 집필한 무료 단원으로, 정렬·재귀·그래프를 글과 JavaScript 과제로 익힌다.
- [DSA Tutorial](https://www.geeksforgeeks.org/dsa/dsa-tutorial-learn-data-structures-and-algorithms/) - Geeks for Geeks / 배열·정렬부터 그래프·DP·세그먼트 트리까지 이어지는 무료 글과 연습 문제 로드맵.
- [영리한 프로그래밍을 위한 알고리즘 강좌](https://www.inflearn.com/course/%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98-%EA%B0%95%EC%A2%8C) - 한국어 / Inflearn / 부경대 권오흠 교수의 무료 55강 강의로 순환, 정렬, 트리, 해싱, 그래프, 동적 계획법을 다룬다.

#### Intermediate
> 중급 강좌

- [Algorithms and Data Structures](https://www.classcentral.com/subject/algorithms-and-data-structures) - Class Central / 대학과 MOOC 플랫폼의 무료·유료 강좌 수백 개를 수강평과 함께 검색할 수 있는 카탈로그.
- [Algorithms](https://www.edx.org/learn/algorithms/iitbombay-algorithms) - edX(IITBombay) / 정렬, 순서 통계량, 문자열·기하·그래프 알고리즘을 다루는 6주 과정으로 청강은 무료.
- [Intro to Algorithms](https://www.udacity.com/course/intro-to-algorithms--cs215) - Udacity / Michael Littman이 소셜 네트워크 분석을 소재로 그래프 알고리즘과 증가율을 가르치는 무료 자율 학습 과정.
- [Introduction to Algorithms, 2020](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/) - MIT OCW / Demaine, Ku, Solomon의 학부 과목 6.006으로 강의 영상, 노트, 문제 세트, 시험과 풀이를 제공한다.
- [Design and Analysis of Algorithms, 2015](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/) - MIT OCW / 분할 정복, DP, 무작위화, 복잡도를 다루는 학부 과목 6.046J로 영상, 노트, 시험을 제공한다.
- [Introduction to Algorithms, 2011](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/) - MIT OCW / Demaine과 Devadas가 가르친 이전 6.006으로 강의·복습 영상, 노트, Python 과제, 시험을 제공한다.
- [Classes and Teaching by Erik Demaine](https://erikdemaine.org/classes/) - MIT(Lecture notes) / Erik Demaine의 6.006, 6.046, 6.851 등 강의 영상과 노트를 모아 둔 목록.
- [Efficient Algorithms and Intractable Problems, 2001](https://people.eecs.berkeley.edu/~jrs/170/) - UC Berkeley(Lecture notes) / Demmel과 Shewchuk의 CS 170 강의 노트와 과제로 그래프, DP, 네트워크 플로우, NP-완전성을 다룬다.
- [Data Structures, 2014](https://people.eecs.berkeley.edu/~jrs/61b/) - UC Berkeley(Lecture notes) / Jonathan Shewchuk의 CS 61B로 Java 기반 노트, 영상, 실습, 프로젝트로 핵심 자료구조를 다룬다.
- [Algorithms, Part I](https://www.coursera.org/learn/algorithms-part1) - Coursera(Princeton University) / Sedgewick과 Wayne의 무료 Java 강좌로 정렬, 탐색, 기본 자료구조를 다룬다.
- [Algorithms, Part II](https://www.coursera.org/learn/algorithms-part2) - Coursera(Princeton University) / Sedgewick과 Wayne의 무료 Java 강좌로 그래프·문자열 알고리즘, 압축, 난해성을 다룬다.
- [USACO Guide](https://usaco.guide) - Bronze부터 Platinum까지 단계별로 구성된 무료 알고리즘 대회 커리큘럼.

#### Advanced
> 고급 강좌

- [Data Structures and Algorithms](https://pll.harvard.edu/course/data-structures-and-algorithms) - 유료 콘텐츠 / Harvard University / Michael Mitzenmacher의 익스텐션 스쿨 과정으로 그래프, 근사, 무작위 알고리즘을 다룬다.
- [Algorithms Specialization](https://www.coursera.org/specializations/algorithms) - 유료 콘텐츠 / Coursera(Stanford University) / Tim Roughgarden의 4개 과정 시리즈로 분할 정복, 그래프, 탐욕법, DP, NP-완전성을 다룬다.

## Competitive programming
> 알고리즘 트레이닝

- [HackerRank](https://www.hackerrank.com/domains/algorithms) - 워밍업부터 동적 계획법까지 주제별로 묶인 알고리즘 연습 문제.
- [Codility](https://app.codility.com/programmers) - 시간 복잡도, 누적 합, 정렬 등을 다루는 무료 강의와 연습 문제.
- [Topcoder](https://www.topcoder.com) - 오랜 역사의 Single Round Match(SRM) 대회와 문제 아카이브, 에디토리얼 제공.
- [Codewars](https://www.codewars.com) - 55개 이상의 언어로 풀 수 있는 커뮤니티 제작 문제(kata).
- [CodeChef](https://www.codechef.com) - 연습 문제와 정기 레이팅 대회.
- [Codeforces](https://codeforces.com) - 영어, 러시아어 / 거의 매주 열리는 레이팅 라운드와 Educational 라운드, 방대한 문제 아카이브와 커뮤니티 블로그.
- [AtCoder](https://atcoder.jp) - 영어, 일본어 / 매주 열리는 Beginner Contest와 Regular, Grand, Heuristic 대회를 여는 일본 AtCoder의 플랫폼.
- [UVa Online Judge](https://onlinejudge.org) - 고전 문제 아카이브. 진행 상황을 추적하는 uHunt와 ICPC Live Archive 포함.
- [A2 Online Judge](https://a2oj.netlify.app) - 서비스가 종료된 a2oj.com 문제 사다리의 보존 미러.
- [ICPC Problem Archive](https://icpc.kattis.com) - Kattis / 최근 ICPC 월드 파이널 기출 문제를 난이도별로 모아 Kattis에서 채점한다.
- [CS Academy](https://csacademy.com) - 영어, 러시아어, 아랍어 / 동적 배점 라운드를 열며 그래프 에디터, 기하 도구 같은 부가 도구를 제공한다.
- [CSES Problem Set](https://cses.fi/problemset/) - 입문 문제부터 고급 기법까지 주제별로 묶인 문제 모음.
- [Coderbyte](https://coderbyte.com) - 영상 풀이가 딸린 코딩 문제. 현재는 채용 평가 플랫폼이 주력.
- [HackerEarth](https://www.hackerearth.com) - 기초 프로그래밍, 자료구조, 알고리즘, 수학 연습 문제와 채용 평가 제공.
- [Infoarena](https://www.infoarena.ro) - 루마니아어 / 본 아카이브와 교육·월간·ACM 아카이브, 대회와 레이팅을 갖춘 커뮤니티 저지.
- [Kattis](https://open.kattis.com) - 난이도 점수가 매겨진 수천 개의 문제 아카이브.
- [Learneroo Algorithms Tutorials](https://www.learneroo.com/subjects/8) - 문제를 풀면서 알고리즘과 자료구조를 배우는 튜토리얼.
- [LeetCode](https://leetcode.com/problemset/) - 영어, 중국어 / 주제와 난이도로 태그된 면접 대비형 문제 은행으로 매주·격주 대회를 연다.
- [Rosalind](https://rosalind.info/problems/locations/) - 생물정보학과 프로그래밍 문제. 초보자용 Python Village부터 시작.
- [ShareCode](https://sharecode.io) - 과거 대회 문제를 모아 둔 읽기 전용 아카이브 온라인 저지.
- [Snakify](https://snakify.org) - 100개 이상의 연습 문제가 있는 초보자용 Python 3 강좌.
- [Sphere Online Judge (SPOJ)](https://www.spoj.com) - 다양한 프로그래밍 언어를 지원하는 대규모 고전 문제 아카이브.
- [beecrowd](https://judge.beecrowd.com) - 영어, 스페인어, 브라질 포르투갈어 / 대회와 방대한 문제 아카이브를 갖춘 저지로, 구 URI Online Judge.
- [PKU JudgeOnline](http://poj.org) - 영어, 중국어 / 베이징대학교가 운영하는 저지로 각지 대회에서 모은 방대한 문제와 월례 대회를 제공한다.
- [Aizu Online Judge](https://onlinejudge.u-aizu.ac.jp) - 영어, 일본어 / 아이즈대학교가 운영하는 무료 저지로 ICPC, JOI, PCK 기출과 입문 코스 등 2,000문제 이상을 제공한다.
- [Project Euler](https://projecteuler.net) - 수학적 통찰과 프로그래밍이 모두 필요한 수학 문제 시리즈.
- [Advent of Code](https://adventofcode.com) - 매년 12월에 하루 한 문제씩 공개되는 퍼즐 캘린더.
- [Project Euler @kr](https://euler.synap.co.kr) - 한국어 / Project Euler 문제의 한국어 번역.
- [Baekjoon](https://www.acmicpc.net) - 한국어 / 국내에서 가장 널리 쓰이는 온라인 저지.
- [solved.ac](https://solved.ac) - 한국어 / 백준 문제의 난이도 티어와 문제 추천.
- [Algospot](https://algospot.com) - 한국어 / 『알고리즘 문제 해결 전략』 저자가 운영하는 온라인 저지와 커뮤니티.
- [JUNGOL](https://jungol.co.kr) - 한국어 / 정보올림피아드 대비 온라인 저지.
- [Koistudy](https://koistudy.net) - 한국어 / 알고리즘별·티어별 문제집과 대회를 제공하는 온라인 저지.
- [CodeUp](https://codeup.kr) - 한국어 / 프로그래밍 입문자를 위한 온라인 저지.
- [Codingdojang](https://codingdojang.com) - 한국어 / 문제 풀이로 코딩 실력을 수련하는 사이트.
- [Programmers](https://school.programmers.co.kr/learn/challenges) - 한국어 / 취업 대비 코딩 테스트 연습 문제.
- [Codeground](https://www.codeground.org) - 영어, 한국어 / 삼성이 운영하며 연습 문제, 사용자가 여는 OpenRound 대회, 대학생 대회 SCPC를 제공한다.
- [SW Expert Academy](https://swexpertacademy.com) - 한국어 / 삼성이 운영하는 소프트웨어 역량 학습 플랫폼. 문제와 강좌 제공.

## Visualizations
> 시각화

- [Algorithm Visualizer](https://github.com/algorithm-visualizer/algorithm-visualizer) - 코드로부터 알고리즘을 시각화하는 인터랙티브 플랫폼.
- [A Visual Guide to Graph Traversal Algorithms](https://workshape.github.io/visual-graph-algorithms/) - Workshape.io가 만든 DFS와 BFS 인터랙티브 설명.
- [VisuAlgo](https://visualgo.net) - 영어, 중국어, 인도네시아어 / 싱가포르국립대 Steven Halim 교수가 만든 자료구조·알고리즘 24개 모듈의 애니메이션 시각화와 퀴즈.
- [Algorithms Visualization](https://bost.ocks.org/mike/algorithms/) - 샘플링, 셔플, 정렬, 미로 생성 알고리즘 시각화를 다룬 Mike Bostock의 글.
- [Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html) - University of San Francisco의 David Galles가 만든 인터랙티브 애니메이션.
- [Sorting Algorithms Animations](https://www.toptal.com/developers/sorting-algorithms) - Toptal이 제공하는 정렬 알고리즘 나란히 비교 애니메이션.
- [Path Finding](https://qiao.github.io/PathFinding.js/visual/) - A*, Dijkstra, BFS, Jump Point Search 등 경로 탐색 알고리즘의 인터랙티브 격자 데모.
- [Introduction to the A* Algorithm](https://www.redblobgames.com/pathfinding/a-star/introduction.html) - Red Blob Games / Amit Patel의 인터랙티브 튜토리얼로 너비 우선 탐색, 다익스트라, 탐욕적 최선 우선 탐색에서 A*까지 단계별로 설명한다.
- [Python Tutor](https://pythontutor.com) - Python, JavaScript, C, C++, Java 코드의 실행 과정을 단계별로 시각화.
- [Algorithm Wiki from Will Thimbleby](https://thimbleby.net/algorithms/) - 실제 JavaScript 구현을 실행해 시각화하는 인터랙티브 위키.
- [TensorFlow Playground](http://playground.tensorflow.org) - 브라우저에서 작은 신경망을 직접 조작해 보는 데모.
- [Algovis](https://github.com/enjalot/algovis) - enjalot이 정리한 알고리즘 시각화 프로젝트·도구 모음으로 Tailspin, Vamonos, Tangle 등을 담고 있다.
- [Vamonos](http://rosulek.github.io/vamonos) - JavaScript 프로그래밍 언어 / 오리건주립대에서 만든 라이브러리로 배열·그래프 알고리즘을 중단점과 되감기로 단계별 시각화한다.
- [The Sound of Sorting](https://panthema.net/2013/sound-of-sorting/) - C ++ 프로그래밍 언어 / Timo Bingmann의 데모로 수십 가지 정렬 알고리즘의 비교 연산마다 막대를 그리고 소리를 낸다.
