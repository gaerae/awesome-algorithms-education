# Awesome Algorithms Education [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)
알고리즘은 문제를 해결하기 위해 따라야 할 규칙의 목록입니다.

알고리즘은 올바른 순서대로 있어야 합니다. 아침에 옷을 입기 위한 일도 알고리즘입니다. 외투를 입고 티셔츠를 위에 입는 다면 어떨까요? 알고리즘을 작성할 때 순서가 매우 중요합니다.

만약 기여하고 싶다면, [기여 가이드](https://github.com/gaerae/awesome-algorithms-education/blob/master/contributing.md) 문서를 확인하세요.

## Courses

## Competitions
> 대회

- [ICPC](https://icpc.global) - 대학생 팀 프로그래밍 대회 중 가장 오래되고 규모가 큰 국제 대회입니다.
- [IOI](https://ioinformatics.org) - 중고등학생을 위한 국제 정보 올림피아드입니다.
- [Meta Hacker Cup](https://www.facebook.com/codingcompetitions/hacker-cup) - Meta가 매년 여는 공개 프로그래밍 대회입니다.
- [AtCoder Contests](https://atcoder.jp/contests/) - 초보자부터 고수까지 참가할 수 있는 주간 레이팅 대회입니다.
- [Codeforces Contests](https://codeforces.com/contests) - 가장 활발하게 열리는 레이팅 대회입니다.
- [Google Coding Competitions Archive](https://github.com/google/coding-competitions-archive) - 2023년에 종료된 Code Jam, Kick Start, Hash Code의 문제와 풀이를 모은 공식 아카이브입니다.
- [Google Summer of Code](https://summerofcode.withgoogle.com) - 오픈 소스 소프트웨어 개발을 위해 학생들을 소개하는 데 초점을 맞춘 글로벌 프로그램이다. 학생들은 대학을 졸업하는 동안 열린 소스 기관과 함께 3개월 동안 프로그래밍 프로젝트를 한다.
- [KOI](https://koi.or.kr) - 한국어 / 한국정보올림피아드.
- [UCPC](https://ucpc.me) - 한국어 / 전국 대학생 프로그래밍 대회 동아리 연합.
