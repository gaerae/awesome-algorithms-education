# Awesome Algorithms Education [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> 알고리즘을 배우고 연습하기 위한 강좌, 온라인 저지, 시각화 도구, 도서, 대회를 엄선한 목록입니다.

유료라고 표시한 항목 외에는 모두 무료로 읽거나 사용할 수 있으며, 한국어 자료에는 따로 표시를 두어 영어와 한국어 학습자 모두가 자신에게 맞는 자료를 찾을 수 있게 했습니다. 알고리즘 구현 코드나 대회 특화 자료는 [Awesome Competitive Programming](https://github.com/lnishan/awesome-competitive-programming#readme)과 [Awesome Algorithms](https://github.com/tayllan/awesome-algorithms#readme)을 참고하세요.

만약 기여하고 싶다면, [기여 가이드](contributing.md) 문서를 확인하세요.

언어: [English](readme-en.md) • **[😎 한국어(Korean)](readme-ko.md)**

## Competitive programming
> 알고리즘 트레이닝

- [HackerRank](https://www.hackerrank.com/domains/algorithms) - 워밍업부터 동적 계획법까지 주제별로 묶인 알고리즘 연습 문제.
- [Codility](https://app.codility.com/programmers) - 시간 복잡도, 누적 합, 정렬 등을 다루는 무료 강의와 연습 문제.
- [TopCoder](https://www.topcoder.com) - 오랜 역사의 Single Round Match(SRM) 대회와 문제 아카이브, 에디토리얼 제공.
- [CodeWars](https://www.codewars.com) - 55개 이상의 언어로 풀 수 있는 커뮤니티 제작 문제(kata).
- [CodeChef](https://www.codechef.com) - 연습 문제와 정기 레이팅 대회.
- [Codeforces](https://codeforces.com) - 영어, 러시아어.
- [AtCoder](https://atcoder.jp) - 영어, 일본어.
- [UVa Online Judge](https://onlinejudge.org) - 고전 문제 아카이브. 진행 상황을 추적하는 uHunt와 ICPC Live Archive 포함.
- [A2 Online Judge](https://a2oj.netlify.app) - 서비스가 종료된 a2oj.com 문제 사다리의 보존 미러.
- [ICPC Problem Archive](https://icpc.kattis.com) - Kattis.
- [CS Academy](https://csacademy.com) - 영어, 러시아어, 아랍어.
- [CSES Problem Set](https://cses.fi/problemset/) - 입문 문제부터 고급 기법까지 주제별로 묶인 문제 모음.
- [CoderByte](https://coderbyte.com) - 영상 풀이가 딸린 코딩 문제. 현재는 채용 평가 플랫폼이 주력.
- [HackerEarth](https://www.hackerearth.com) - 기초 프로그래밍, 자료구조, 알고리즘, 수학 연습 문제와 채용 평가 제공.
- [Infoarena](https://www.infoarena.ro) - 루마니아어.
- [Kattis](https://open.kattis.com) - 난이도 점수가 매겨진 수천 개의 문제 아카이브.
- [Learneroo Algorithms Tutorials](https://www.learneroo.com/subjects/8) - 문제를 풀면서 알고리즘과 자료구조를 배우는 튜토리얼.
- [LeetCode](https://leetcode.com/problemset/) - 영어, 중국어.
- [Rosalind](https://rosalind.info/problems/locations/) - 생물정보학과 프로그래밍 문제. 초보자용 Python Village부터 시작.
- [ShareCode](https://sharecode.io) - 과거 대회 문제를 모아 둔 읽기 전용 아카이브 온라인 저지.
- [Snakify](https://snakify.org) - 100개 이상의 연습 문제가 있는 초보자용 Python 3 강좌.
- [Sphere Online Judge (SPOJ)](https://www.spoj.com) - 다양한 프로그래밍 언어를 지원하는 대규모 고전 문제 아카이브.
- [beecrowd](https://judge.beecrowd.com) - 영어, 스페인어, 브라질 포르투갈어. 구 URI Online Judge.
- [PKU JudgeOnline](http://poj.org) - 영어, 중국어.
- [AIZU ONLINE JUDGE](https://onlinejudge.u-aizu.ac.jp) - 영어, 일본어.
- [Project Euler](https://projecteuler.net) - 수학적 통찰과 프로그래밍이 모두 필요한 수학 문제 시리즈.
- [Advent of Code](https://adventofcode.com) - 매년 12월에 하루 한 문제씩 공개되는 퍼즐 캘린더.
- [Project Euler @kr](https://euler.synap.co.kr) - 한국어 / Project Euler 문제의 한국어 번역.
- [Baekjoon](https://www.acmicpc.net) - 한국어 / 국내에서 가장 널리 쓰이는 온라인 저지.
- [solved.ac](https://solved.ac) - 한국어 / 백준 문제의 난이도 티어와 문제 추천.
- [Algospot](https://algospot.com) - 한국어 / 『알고리즘 문제 해결 전략』 저자가 운영하는 온라인 저지와 커뮤니티.
- [JUNGOL](https://jungol.co.kr) - 한국어 / 정보올림피아드 대비 온라인 저지.
- [Koistudy](https://koistudy.net) - 한국어 / 알고리즘별·티어별 문제집과 대회를 제공하는 온라인 저지.
- [CodeUp](https://codeup.kr) - 한국어 / 프로그래밍 입문자를 위한 온라인 저지.
- [Codingdojang](https://codingdojang.com) - 한국어 / 문제 풀이로 코딩 실력을 수련하는 사이트.
- [Programmers](https://school.programmers.co.kr/learn/challenges) - 한국어 / 취업 대비 코딩 테스트 연습 문제.
- [Codeground](https://www.codeground.org) - 영어, 한국어.
- [SW Expert Academy](https://swexpertacademy.com) - 한국어 / 삼성이 운영하는 소프트웨어 역량 학습 플랫폼. 문제와 강좌 제공.

## Visualizations
> 시각화

- [Algorithm Visualizer](https://github.com/algorithm-visualizer/algorithm-visualizer) - 코드로부터 알고리즘을 시각화하는 인터랙티브 플랫폼.
- [A Visual Guide to Graph Traversal Algorithms](https://workshape.github.io/visual-graph-algorithms/) - Workshape.io가 만든 DFS와 BFS 인터랙티브 설명.
- [VisuAlgo](https://visualgo.net) - 영어, 한국어, 중국어, 일본어.
- [Algorithms Visualization](https://bost.ocks.org/mike/algorithms/) - 샘플링, 셔플, 정렬, 미로 생성 알고리즘 시각화를 다룬 Mike Bostock의 글.
- [Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html) - University of San Francisco의 David Galles가 만든 인터랙티브 애니메이션.
- [Sorting Algorithms Animations](https://www.toptal.com/developers/sorting-algorithms) - Toptal이 제공하는 정렬 알고리즘 나란히 비교 애니메이션.
- [Path Finding](https://qiao.github.io/PathFinding.js/visual/) - A*, Dijkstra, BFS, Jump Point Search 등 경로 탐색 알고리즘의 인터랙티브 격자 데모.
- [Introduction to the A* Algorithm](https://www.redblobgames.com/pathfinding/a-star/introduction.html) - Red Blob Games.
- [Python Tutor](https://pythontutor.com) - Python, JavaScript, C, C++, Java 코드의 실행 과정을 단계별로 시각화.
- [Algorithm Wiki from Will Thimbleby](https://thimbleby.net/algorithms/) - 실제 JavaScript 구현을 실행해 시각화하는 인터랙티브 위키.
- [TensorFlow Playground](http://playground.tensorflow.org) - 브라우저에서 작은 신경망을 직접 조작해 보는 데모.
- [Tangle](https://github.com/enjalot/algovis) - JavaScript 프로그래밍 언어.
- [Vamonos](http://rosulek.github.io/vamonos) - JavaScript 프로그래밍 언어.
- [The Sound of Sorting](https://panthema.net/2013/sound-of-sorting/) - C ++ 프로그래밍 언어.

## Books

- [Open Data Structures](https://opendatastructures.org) - 무료.
- [Hello Algo](https://github.com/krahets/hello-algo) - 무료 / 영어, 중국어, 일본어 등.
- [CRACKING the CODING INTERVIEW](https://www.crackingthecodinginterview.com) - [GitHub](https://github.com/careercup/CtCI-6th-Edition), [Quora](https://www.quora.com/profile/Gayle-Laakmann-McDowell).

- [Introduction to Algorithms](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/) - Cormen, Leiserson, Rivest, Stein의 CLRS 교재 4판.
- [Grokking Algorithms](https://www.manning.com/books/grokking-algorithms) - Aditya Bhargava의 그림으로 설명하는 입문서. Manning 출판.
- [프로그래밍 대회에서 배우는 알고리즘 문제 해결 전략](https://book.algospot.com) - 한국어 / 대회 문제를 풀며 알고리즘 설계를 배우는 구종만의 교재.

## Competitions

- [AtCoder Contests](https://atcoder.jp/contests/) - 초보자부터 고수까지 참가할 수 있는 주간 레이팅 대회입니다.

- [KOI](https://koi.or.kr) - 한국어 / 한국정보올림피아드.
- [UCPC](https://ucpc.me) - 한국어 / 전국 대학생 프로그래밍 대회 동아리 연합.
