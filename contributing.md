# Contribution guidelines

* Practice common sense and observe applicable [Awesome List Guidelines](https://github.com/sindresorhus/awesome/blob/main/contributing.md).
* Proof-read yourself.
* Please be nice.
* Be brave with contributing and commenting.
* Consider if the item you're adding to the list is actually pretty useful and/or exciting for newcomers or expert programmers.
* In case we gather a lot of links that are kinda-useful, but not exactly awesome, we could create another list within the repo.

## Adding an item

* Add the item to **both** `README.md` and `README.ko.md` in the same section and position, so the two lists stay in sync.
* Use the format `- [Name](https://link) - Short description.` and prefer `https://` links. End descriptions with a period.
* Mark non-English resources with the language (for example `- Korean.`) and paid resources with `Paid Content.`
* Do not add link-building or promotional content. Resources must be about learning or practicing algorithms and freely accessible to read, even if some features are paid.
* Check that the link works before opening a pull request. CI runs [awesome-lint](https://github.com/sindresorhus/awesome-lint) and a link checker on every pull request.

## Code of conduct

This project follows the [Contributor Covenant](code-of-conduct.md). By participating you agree to keep interactions respectful.
